# postgresl - kuberentes - cluster

## setup

- add ansible_host_key_checking in ~/.bashrc file

```sh
export ANSIBLE_HOST_KEY_CHECKING=false
```

```sh
vagrant init
```

- start vagrant with cluster

```sh
vagrant up
```
